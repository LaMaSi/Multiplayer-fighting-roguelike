# Economy, Shops and Meta Progression

Part 1 is decided. Part 2 (in-run shops) is OPEN and needs its own session. Overrides `PLAN.md` on meta progression and the earlier "reward cards" flow where they conflict.

## 1. Decided

### Run start loadout (no re-roll at start)
- 3 random B moves from the player's class (★ moves, in B, B+Forward, B+Up)
- 1 random adaptive move (Y, ★)
- 1 random universal move (X, ★, an attack-type move so every player can hit up close)
- There is **no reroll** at the start of a run.
- Meta progression can later unlock: re-rolling individual starting moves, and starting with more moves.

### Meta progression (between runs)
- A **meta meter** fills based on the **level score**, both when a level is completed **and** when a player dies. So every attempt moves the player forward.
- The player spends the points on:
  - **New moves**, unlocked one after another (a fixed order, so the unlock list is visible)
  - **Generic features** from a list, for example: individual move rerolls at run start, more starting moves, more HP, more revives
- Magic (class) is locked behind this progression.
- Interpretation to confirm: points are earned when the meter fills (1 fill = 1 point), the score of both players is combined for the shared run (a team score), and each player's progression is shared (one save).

## 2. In-run shops: planning session (OPEN)

Proposal from you: instead of learning moves from reward cards only, **there is currency and new moves are bought in shops**. Goals:
1. **Every run should be interesting** (different decisions, different builds).
2. Players make **mid-term decisions** (save or spend, take the risky node or the shop, which move to replace).
3. It must follow the co-op pillar (`DESIGN.md`): spending should create conversation, not two people shopping separately.

### Questions for the session
1. **What happens to the reward screens?** Options: (a) shared X/Y card choice stays as a free pick, and shops sell extra moves and upgrades; (b) the shared card choice disappears, X/Y moves are only bought in shops; (c) the cards become the shop stock (a free pick every level, a paid reroll).
2. **One wallet or two?** Proposal: one **shared wallet**, so every purchase needs agreement (simultaneous vote, RPS on a tie). That forces a conversation. Alternative: personal wallets plus a "give money" action.
3. **What is sold?** X/Y moves, B moves, move upgrades, heals, extra revives, consumables, temporary boons for the next level.
4. **Where does currency come from?** Level score and rank, broken containers, combos, protecting the partner, elites. Not from plain kills.
5. **How many shops per run and where?** A shop node on the map (a branching choice), and a rest/heal node as the alternative.
6. **What else makes each run different** besides moves? Ideas: per-run modifiers/mutators chosen at the start (e.g. "enemies drop crates", "double projectiles"), random node events with risk and reward, elite variants, shop stock variance, biome events, boons that change a move's behaviour.
7. **Does the personal level-up stay?** (new B moves, empower, max HP, team card). Proposal: yes, it stays free, and the shop is for X/Y moves and upgrades.
8. **Anti-frustration:** pity rules so that the shop always offers at least one usable move, and a price for rerolling stock.

### Draft (to react to, nothing is decided)
- Level clear: personal level-up (free) + currency based on score and rank.
- Map nodes: Fight, Elite (harder, more currency), Shop, Rest, Mystery event, Boss.
- Shop: 3-5 items (moves, upgrades, heal), shared wallet, vote to buy, reroll costs currency.
- Mutators: choose 1 of 3 at run start for variety.
